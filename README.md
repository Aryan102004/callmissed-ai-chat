🚀 CallMissed AI - Multimodal AI Assistant

A modern, full-stack AI assistant built with **Next.js 16**, **TypeScript**, and the **CallMissed AI API**. The application provides a seamless experience for AI-powered conversations, image generation, and image understanding through an elegant and responsive interface.

✨ Features

💬 AI Chat
- Real-time AI conversation
- Streaming responses
- Markdown support
- Code syntax highlighting
- Modern chat interface

🎨 AI Image Generation
- Generate AI images from text prompts
- Intelligent prompt optimization
- Download generated images
- Beautiful preview interface

👁️ AI Vision
- Upload images
- Ask questions about uploaded images
- AI-powered image understanding
- Image preview with detailed analysis

🎨 Modern UI
- Dark premium interface
- Black & Violet theme
- Responsive layout
- Glassmorphism design
- Smooth animations
- Professional dashboard

🛠️ Tech Stack

Frontend

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide React

AI Models

- kimi-k2.7-code — AI Chat
- kimi-k2.7-code — Vision
- flux-2-klein-9b — Image Generation

Libraries

- React Markdown
- Remark GFM
- React Syntax Highlighter

🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/callmissed-ai-chat.git

cd callmissed-ai-chat
```
## Install dependencies

```bash
npm install
```
Configure Environment Variables

Create a `.env.local` file.

```env
CALLMISSED_API_KEY=your_api_key_here
```
## Run the development server

```bash
npm run dev
```

Visit
```
http://localhost:3000
```

# 🏗️ Build

```bash
npm run build
```

🚀 Deployment

This application is optimized for deployment on **Vercel**.

Deploy directly from GitHub by importing the repository into Vercel and adding your environment variables.
